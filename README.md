# Jungle Quest — Jungle Brick Breaker 🌴

[**Play Jungle Quest →**](https://laurenlambrecht.github.io/CursorPlay2/)

A colorful, browser-based brick-breaker built with HTML Canvas and vanilla JavaScript.

## How to play
- **Mouse / trackpad:** Move horizontally to position the fist paddle.
- **Touch:** Drag your finger across the playfield.
- **Keyboard:** Use **←** and **→** to move.
- **Pause:** Press **P** or **Space**, or use the pause button.
- Break all bricks to advance automatically to the next level.
- You begin with three lives and earn a bonus life every three levels (up to five).

## What's new
- Endless level progression, growing brick layouts, and gradually increased ball speed
- More responsive paddle movement with a persistent visible pointer and bright aiming ring
- Pointer, touch, and keyboard support
- Clearer level HUD, pause state, and feedback
- Collision improvements and easier starting difficulty

Entirely client-side; no installations or dependencies needed. Open `index.html` locally or play via GitHub Pages.
